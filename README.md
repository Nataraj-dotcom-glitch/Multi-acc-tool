# Dark Alise Ultimate Multi-Account Control Panel

## Features
- **Dark Alise Branding & UI**: Sleek dark theme matching professional Discord management panels with glowing orange/purple accents.
- **Multi-Account & Multi-Token Management**: Input multiple tokens, select active accounts via checkboxes, and switch server views easily.
- **Voice Channel Control**: Connect multiple accounts simultaneously to voice channels with **Self-Mute** and **Self-Deafen** enabled by default.
- **Amplifier & Audio Settings**: Adjust Gain (dB), Air Quality, and Bass Boost in real-time.
- **24/7 Audio/Video Streaming & Soundboard**: Upload audio (`.mp3`/`.wav`) or video files to loop continuously across connected bots.
- **Infiltrate User**: Automatically fetch and target members inside the voice channel.

## Quick Start
1. Run `npm install` to install dependencies.
2. Run `npm start` to launch the server.
3. Open `http://localhost:3000` in your browser.
